# Celebration assignments and issue alerts

Shared service changes and operational issue updates now enter the existing planning notification bell. Recipients are current celebration coordinators and the currently assigned person, excluding the actor. Event-only readers are not notified merely for being invited. Existing category preferences apply under Assignments & shared updates. Current access, assignment and record revision are checked again for inbox reads, RLS, notification navigation and optional daily email summary counts. Revoked/expired access, reassignment, archived weddings, superseded updates and disabled categories hide the old alerts.

Notifications contain generic labels and links, never service titles, menus, briefs, issue details or resolution notes. The issue board and the highlighted service still require their normal event access. A resolved issue opens the All view so its resolution can be found; cancelled services open the archive view. No chat messages, instant email dispatch, external vendor messages, tasks or payments are created. Existing opted-in daily summaries can count eligible unread updates; this does not enable email for anyone.

Activation: run supabase/experience-notifications.sql after shared-experience.sql, experience-issues.sql and the existing planning notification/email setup. Additive and rerunnable. It preserves all currently accepted source kinds and the private reminder project constraint. No historical alerts are backfilled.

Validation: native SQL on real planning inbox, email digest, project access and experience functions covers recipient privacy, exact-retry deduplication, current revisions, expired access, preference changes, resolved issues, archive and raw/helper/anonymous denials. Mobile browser tests cover authorization before navigation, issue-board opening, archived-service highlighting and no overflow. Existing experience/issue/notification and authentication regressions are checked. No production messages or emails are sent by tests; live multi-device tests remain deferred.
