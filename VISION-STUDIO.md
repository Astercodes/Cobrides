# Bridal Vision Studio — Module 02

## Workspace
The existing #vision route now opens a six-section studio: Discover, My Boards, Design Studio, My Looks, Collaborate, Make It Happen. Its stage-aware introduction, project selector, saved/shortlisted/approved/connected counts and history reflect the current project. The CoBrides palette, rounded controls, black typography and permanent navigation remain.

## Working features
- Structured records: title, category/subcategory, event, source/creator, source accessibility, media rights, notes, style, HEX or RGB colors, tags, indicative price/currency/FX, priority/status, assigned vendor/owner, pros/cons, personal comments, favorite/pin/archive, version and execution links.
- Board creation/editing, nested collections with cycle prevention, status, duplication through shared canonical membership, merge, archive/restore, bulk copy/move and desktop drag-to-collection. Existing inspirations migrate without deletion. The last active board cannot be archived.
- Grid, masonry, collage and list presentations; keyword/status filtering; favorites and pins; two-to-four-way comparisons. Categories can be renamed, added or removed from the category menu without destroying existing records.
- Multi-image selection and file drop. Up to eight originals per batch (JPEG/PNG/WebP, 8 MB each), resized to 1000 pixels maximum, with explicit ownership/permission acknowledgment, hash-based duplicates, 3 MB total saved-image ceiling and storage preflight. Upload is atomic; a failed batch does not retain partial records. Stored media can be removed after reopening a locked concept. Full journey backups contain these photographs.
- Live Wikimedia discovery, original sources and attribution through the existing integration adapter. Google Places discovery remains credential-dependent. Universal linked imports retain the existing review inbox. A discovered result saves for review; it does not create a purchase or grant image-reuse rights.
- Palette versions, HEX and RGB input, complementary/analogous hue relationships, local raster color extraction, sample styling previews, code copying and SVG palette export. Selected palettes apply to wedding website accents and stationery previews. Theme concepts, cultural/venue constraints and selected theme are recorded separately.
- Styling category view links to the existing Wardrobe workspace for event looks, wearer records, fittings and accessories.
- Approval locks creative field edits until explicitly reopened. Feedback is the bride's own locally recorded reflection. Linked decision proposals remain Draft, with actual approval handled in the existing Decisions workspace. No collaborator impersonation, invitation delivery or permissions enforcement is claimed.
- Creative brief snapshots retain selected sources, notes, creator attribution, palettes, priority/status, events/vendors, estimates and owned/permitted image references. Each snapshot is immutable independently of later inspiration edits. Download printable HTML and use the browser's Print / Save as PDF. Palette images export as SVG; board image/PPT export is not implemented.
- Make It Happen creates reviewed Shopping, Budget, Task, Decision, Wardrobe, Honeymoon itinerary, Home need, Registry and Operations records. Budget and shopping references synchronize their canonical expense links; registry/home/wardrobe reuse the shopping record. Existing source-matched shopping records are reused. Operations requires an event and a valid within-day time. Repeated conversion reuses the existing record rather than duplicating it. No order, booking, payment, quote request or sent approval is inferred.
- Optional AI assistant uses the server-side OpenAI Responses adapter, Google session/CSRF protection, allowlisted selected inspiration fields, explicit submission, ten requests/account/hour and store:false. Results are marked AI-generated and do not verify products, vendors, prices or availability. Requires OPENAI_API_KEY and OPENAI_MODEL in Vercel in addition to the existing Google/storage setup. No API key was supplied and no real AI request was made during testing. Local extraction is not labeled AI.

## Privacy and persistence
All boards remain private browser-local records. General search/activity treat studio boards/palettes/themes and private inspiration as personal records; include-private search is a deliberate owner view, not multi-user authorization. Spiritual-category inspirations cannot be converted to shared execution records or included in vendor briefs. Full local backups and explicitly requested collection exports still include selected personal content. Provider account connection does not synchronize the complete studio between devices.

Cross-device board synchronization, secure invited collaborators, live partner voting/comments, native share extensions, browser extensions, authorized social media extraction, cloud photo/file pickers, trending feeds, verified product/availability matches, vendor response ingestion, video storage, floor-plan/3D/AR tools and automatic order/booking workflows remain outside this implementation. Existing provider adapters and external handoff screens are used where available rather than simulated as completed transactions.
