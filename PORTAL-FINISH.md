# Portal visual finish

portal-finish.css is loaded last by the 22 authenticated workspace documents. It scopes the bridal portal, participant sidebars and shared workspace components; public landing and guest wedding website documents retain their own design styles. Authentication scripts and workflow behaviour are preserved.

The bridal shell uses rich magenta and violet from Cobridey's jewel palette, opaque white chapter navigation, magenta/violet actions, clean neutral content surfaces, stronger card edges, restrained shadows and tabular figures. Central has a compact teal summary and the existing budget summary uses plum. Palette/stationery source artwork is unchanged. Light board labels and photo badges retain black text. Mobile keeps the hidden menu drawer and existing focus management; reduced-motion preferences are respected. Broken replacement glyphs in the legacy conversation options label were replaced with a readable Options label.

Visual QA: set CB_PLAYWRIGHT_PATH, then run node portal-finish.preview.cjs. This uses an isolated test-origin fixture and the existing Amara/Tobi sample seed, never a live account or a production authentication bypass. The test tool is not included in the static build. It renders 13 existing portal routes at desktop width, checks no overflow and opaque white navigation, checks light board-label contrast, and tests the mobile drawer and Escape close. It saves 2× PNG previews in Downloads. Native SQL/backend workflows are not exercised by this presentation fixture.

Preview routes: Central, budget, tasks, Vision Studio, preparation, communication, registry, wedding projects, timeline, vendors, shopping, memories and honeymoon. Screenshots were visually inspected for Central, budget, Vision Studio, tasks, communication, preparation and the mobile shell/drawer. Existing profile data, counts and financial values are used; no charts or statistics were invented for the redesign.
